# ISA_2025-2026
We collect documentation and code for the ISA Labs 2025/2026

This directory contains the following materials:

I-O
- Simulation outputs generated by the VHDL data_sink
- MATLAB outputs (resultsm and samples)
- C++ implementation outputs (resultsc)

Innovus
- design: Innovus files for visualizing the die
- reports and timing reports: output files produced by report commands

Prototypes
- MATLAB and C++ implementations

SIM/scripts
- Files for simulating and verifying the functionality of filter_core, filter_core_pipe_10Tadd
(testbench files test_core and test_core_pipe) and netlists generated by Design Vision and Innovus

src
- VHDL source files: components and architectures for the base design (filter_core) and the pipelined version (filter_core_pipe_10Tadd)

SYN/report
- Power, area, and timing (slack) reports

SYN/scripts
- applying_constraints: applies clock-related constraints
- create_: generates the netlist and SDF files using Design Vision
- pwr_est_: estimates power using .vcd files generated by QuestaSim
- reading_source_files: analyzes source files before synthesis
- setup.tcl: imports Synopsys libraries

Tb
- Testbench directory: for each tested architecture, corresponding versions of clk_gen, data_maker, and data_sink are included
- Testbench files have prefix tb_
	- tb_fir: base architecture
	- tb_fir_pipe_10Tadd: pipelined architecture

We kept the files required to reproduce the results and tried not to remove anything important. If anything essential is missing, the complete material can be found in the LAB1 folder of our group's repository in the course Git class.
